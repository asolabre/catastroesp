# catastroesp
Herramientas de carga, información, gestión y edición de Catastro

      - Busqueda por RC, individual y masiva, por PROC/MUNI/POL/PAR,
        por listas en texto libre con separadores.
      - Identificador y carga de parcela en pantalla.
      - Carga del catastro completo por municipio pinchado.
      - Carga de catastro historico (desde 2002)
      - Carga masiva desde los registros de una capa con un campo RC.
      - Carga de parcelas catastrales solapadas con un polígono
      - Borra de la vista parcelas cargadas por cursor
      - Asigna atributos de parcela de una capa a parcela pinchada en capa activa
      - Herramienta para adaptar parcelas a una superficie (PRUEBA)
      - Generar GML de parcelas desde un Fichero de polígonos
      - Generar GML de CONSTRUCCIONES desde un Fichero de polígonos
      - Carga resultado Consulta catastral Masiva
      - Depuración topológica de poligonos
      - Listado de coordenadas de un polígonoListado de coordenadas de un polígono
      ...
      - Otras herramientas
