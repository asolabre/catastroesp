# catastroesp
Tools for loading, information, management and editing of the Spanish Cadastre
      - Search by RC, individual and bulk, by PROC/MUNI/POL/PAR, by free text lists with separators
      - Parcel identifier and loading on screen
      - Upload the complete cadastre by municipality (clicked)
      - Historical cadastral data upload (since 2002)
      - Bulk load from the records of a layer with an RC field
      - Load of cadastral parcels overlapping with a polygon
      - Deletes plots loaded by cursor from view
      - Assigns plot attributes of a layer to plot clicked on active layer
      - Generate GML files of PARCELS or BUILDINGS from a polygon file
      - Upload results of bulk alphanumeric cadastral query
      - Topological refinement of polygons
      - List of coordinates of a polygon

Herramientas de carga, información, gestión y edición del Catastro de España
      - Busqueda por RC, individual y masiva, por PROC/MUNI/POL/PAR,
        por listas en texto libre con separadores
      - Identificador y carga de parcela en pantalla.
      - Carga del catastro completo por municipio pinchado.
      - Carga de catastro historico (desde 2002)
      - Carga masiva desde los registros de una capa con un campo RC.
      - Carga de parcelas catastrales solapadas con un polígono
      - Borra de la vista parcelas cargadas por cursor
      - Asigna atributos de parcela de una capa a parcela pinchada en capa activa
      - Herramienta para adaptar parcelas a una superficie (PRUEBA)
      - Generar GML de parcelas desde un Fichero de polígonos
      - Generar GML de CONSTRUCCIONES desde un Fichero de polígonos
      - Carga resultado Consulta catastral Masiva
      - Depuración topológica de poligonos
      - Listado de coordenadas de un polígono
      ...
      - Otras herramientas
